## [**Programa convertidor de moneda**](main.py)

El programa que nos decidimos por realizar es una calculadora / convertidora de pesos mexicanos a dolar estadounidense y viceversa, apoyé a mi compañero un poco con la teoría pero al final nos decidimos por realizarlo individual, hice unos añadidos a mi programa para que cumpliera de mejor manera los criterios del proyecto

Se añadió una variable name para saludar al usuario y cumplir con el tipo de dato STRING por defecto del input, de igual manera añadí un switch case denominado aquí Match para cumplir con el tipo de dato INT (opción) y finalmente manejamos las respectivas monedas en float.
El programa al ingresar da la bienvenida al usuario, muestra las opciones disponibles y el cambio actual, despues dependiendo de cada case pide la cantidad en moneda, multiplica o divide respectivamente y muestra el resultado al final.
